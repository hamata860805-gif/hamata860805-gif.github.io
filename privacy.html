プライバシーポリシー(haru uploader)

最終更新日: 2026年11月21日

1. このツールについて

haru uploader は、YouTube チャンネル「黒柴ハルのAIゲーム部」の運営者が、自分のチャンネルへ自分の動画を非公開でアップロードするための個人用ツールです。運営者本人以外は利用しません。

2. 使用する Google のデータと権限

  • YouTube への動画のアップロード(youtube.upload)
  • アップロードした動画への字幕の追加と、アップロード先が自分のチャンネルであることの確認(youtube.force-ssl)

これ以外の Google アカウントのデータ(メール、連絡先、ファイルなど)にはアクセスしません。

3. データの保存

認証のための情報(アクセストークン・リフレッシュトークン)は、運営者のパソコンの中だけに保存し、運営者本人だけが読める設定にしています。外部のサーバーや第三者には送信・共有しません。アップロードの結果(動画ID・日時)だけを、運営者のパソコンに記録します。

4. 第三者への提供

取得したデータを第三者に提供・販売することはありません。Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

5. YouTube の規約

このツールは YouTube API サービスを使用しています。YouTube 利用規約 と Google プライバシーポリシー もあわせてご確認ください。

6. アクセス権の取り消し

このツールに与えたアクセス権は、Google アカウントのセキュリティ設定 からいつでも取り消せます。

7. お問い合わせ

YouTube チャンネル「黒柴ハルのAIゲーム部」の運営者までお問い合わせください。
